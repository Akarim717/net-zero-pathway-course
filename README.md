# Planning a Net-Zero Pathway

Open `index.html` in a modern browser to use the course.

The course includes:

- a four-week, 18-hour learning journey;
- an organisational carbon boundary activity;
- an editable carbon baseline calculator;
- a Greenfield Training Centre practice dataset;
- an action prioritisation matrix;
- a live one-page net-zero roadmap;
- automatic saving on the learner's device; and
- print/PDF-ready course pages and roadmap.

Illustrative emission factors are included only for practice. Learners should replace them with current, locally appropriate official factors before using results for organisational reporting or public claims.
